## 1. Problem Statement

ChordLab’s core idea starts with exploring compatible chords in a musical key. Users need to choose a key and scale and immediately see the diatonic chords available to them.

## 2. Goals

- Let users choose one of twelve roots and an MVP-supported scale.
- Derive and display the seven diatonic triads for the selected scale.
- Show chord symbols, qualities, Roman numerals, and notes.
- Make each chord selectable by the progression workspace.

## 3. Non-Goals

- Advanced jazz harmony, borrowed chords, custom scales, or chord voicing search.

## 4. Personas & User Stories

- **As a beginner**, I want to see the chords in a key so I can learn what belongs together.
- **As a songwriter**, I want to select a compatible chord so I can add it to a progression.

## 5. Functional Requirements

- **FR-1.** The UI MUST provide root and scale selectors.
- **FR-2.** The system MUST derive one triad per scale degree.
- **FR-3.** Each chord MUST expose symbol, notes, quality, and Roman numeral.
- **FR-4.** Changing key or scale MUST refresh the chord list.
- **FR-5.** Invalid selections MUST be prevented or shown with an actionable error.

## 6. Non-Functional Requirements

- **Performance** — local derivation SHOULD complete in 50 ms.
- **Accessibility** — selectors and chord choices MUST be keyboard accessible.

## 7. Acceptance Criteria

- **AC-1.** Given C major, when the explorer loads, then it shows C, Dm, Em, F, G, Am, and B diminished.
- **AC-2.** Given a changed root, when the list updates, then every chord reflects the new root.
- **AC-3.** Given a chord card, when it is activated, then the workspace receives its stable chord data.
- **AC-4.** Given an API or derivation error, when the explorer fails, then the shared error state offers recovery.

## 8. Data Model

Use local typed Scale and Chord models from the specification. Persistence is not required.

## 9. API Surface

Use local reference data or a read-only `GET /api/scales` and `GET /api/scales/:scaleId/chords` contract. Keep this implementation limited to read operations.

## 10. UI / UX

Create the main explorer panel with selectors, chord cards, selected state, loading state, empty state, and error state.
